关注地点

用于计算主要动（S 波）到达倒计时与本地预计震度。也可以直接点击地图选点。

当前：—

最多再挂 3 个点：事件卡会同时列出各点的预计震度， 任何一点达到阈值都会响警报，卡片大数字仍显示主关注点。

告警

至次日 点
低于 M 不响铃、不弹桌面通知（卡片照常显示）

关注点预估震度/烈度 ≥ 阈值才响警报音，可自由输入。 全球检测（GQ）没有本地震度概念，按「弹窗震级」单独判定：达到就弹事件卡 + 响铃 + 桌面通知， 不受关注点远近影响；列表最小震级只影响「最近地震」里显示多少。 桌面通知需要浏览器授权，窗口最小化时也能看到。

外观

浅色模式会把面板和底图一起换成浅底深字（强度色、震度配色不变）。 也可以点右上角的太阳/月亮按钮或按 T 键切换；选择记在这台设备上。

地图

地图左右无缝衔接，可以一直往东/往西拖动绕地球一圈，没有断开的边缘。 同屏最多同时显示 1~10 起地震的 P/S 波前（主事件最亮，其余淡一些）。 P 波圈快撞到屏幕边缘时，视野会平滑拉远，让整圈波前一直看得到；手动缩放过会暂停 3 秒再接管。 打开「自动跳到震中」后，每当有够格上卡的地震就飞过去；事件收卡 10 秒仍没有新地震， 自动飞回中国+日本全景（自己拖过或缩放过会先让 5 秒，不抢操作）。

语音包

只加载你标注过语义的 — 段；未标注的数字文件已全部丢弃。 含 海啸注意报 / 警报 / 大警报（警报先响前奏再念等级）、 震度速報 / 震度結果（6弱以上用专用那句）。 「测站提示音」和「播报」是两条独立的声道：测站只发提示音，不念人声； 播报（事件/预想震度/最终报）才用语音包里的人声，由下面的「人声发音」开关决定。

1.6×

台站摇晃退去的快慢：往左快、往右慢，默认 1.6×（可拉到 6×）。觉得震度掉得还是太快就往右拉；调到 3× 以上，震度 1~2 的余晃能挂好几分钟。

数据源

按延迟升序排列，标「主」的是当前同类里延迟最低的一个（每 10 秒重算）。 需要令牌的源显示「待授权」：把令牌填进 data/tokens.json 即刻生效。

自动录屏

达到设定震级时自动录一段地图画面（带震级 / 地点 / 时间的叠加条）， 存成 .webm 放到你选的目录。只录地图，不含左侧浮层卡片；录制中右上角有红点。

熄屏也能录：自动录屏开着时，系统会被守住不休眠 （显示器照常熄灭，省电），人出门锁屏后地震来了照样录。关掉开关即解除。

整窗模式连卡片、面板一起录，画面和屏幕一致；熄屏时抓不到窗口， 会自动退回地图模式。窗口被别的窗口挡住也不影响（直接抓窗口自己的画面）。

录到你自己点「停止」为止；顶部胶囊随时可停。

每个源各设两条线：震级和强度，两条都过才录。 强度填震度档（3 = 震度3、5.5 = 5強），中国填烈度（4 = Ⅳ度）；用的是该事件自己的最大震度，不看关注点。
